# Leo Sardinha.Math

Site educacional estático, preparado para GitHub Pages.

## Estrutura

- `index.html`: página inicial
- `educacao.html`: jogos e recursos
- `sobre.html`: apresentação do projeto
- `classroom.html`: acesso ao Google Classroom
- `imagens.html`: temas visuais
- `jogos/batalha-naval/`: Batalha Naval Matemática 10×10

## Publicação

Nas configurações do repositório, abra **Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/ (root)`.
