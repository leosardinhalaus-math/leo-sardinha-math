# Leo Sardinha.Math

Site educacional estático, preparado para GitHub Pages.

## Estrutura

- `index.html`: página inicial
- `educacao.html`: jogos e recursos
- `sobre.html`: apresentação do projeto
- `classroom.html`: acesso ao Google Classroom
- `imagens.html`: temas visuais
- `jogos/batalha-naval/`: Batalha Naval Matemática 10×10

## Publicação

Nas configurações do repositório, abra **Pages** e selecione **GitHub Actions** como fonte. O workflow **Godot Web and Android** preserva o site estático e publica o jogo Godot compilado junto dele.

## Calculus Royale em Godot 4

O projeto Godot está na raiz. Veja [README_GODOT.md](README_GODOT.md) para jogar,
exportar Web/APK e configurar o workflow de publicação em GitHub Pages.
