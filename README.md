# APK do Leo Sardinha 1.1

[Baixar APK](https://github.com/leosardinhalaus-math/leo-sardinha-math/raw/refs/heads/apk-leo-sardinha-1.1/apk-do-leo-sardinha-1.1.apk)

Editor de textos sem anúncios. Rascunhos locais, revisão básica em português, abertura de TXT, visualização de JPG/PNG, seletor alternativo e integração com Abrir com. Não pede acesso a pastas inteiras nem permissões de internet ou armazenamento amplo.

Instale abrindo o APK no Android. Para atualizar uma instalação compatível, mantenha o aplicativo instalado para preservar rascunhos. A versão aparece como 1.1 na tela inicial.

Compilação e assinatura verificadas. Não testado em aparelho/emulador Android 16; o problema relatado de seleção de pastas não foi reproduzido.
