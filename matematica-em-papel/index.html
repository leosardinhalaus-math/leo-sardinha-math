Como usar os outros módulos
  1. Escolha uma aba e personalize os campos. As imagens ficam no seu navegador.
  2. Use “Imprimir / PDF” e selecione papel A4, escala 100%, sem cabeçalhos e rodapés. Ative gráficos de fundo para manter as cores.
  3. Use “Baixar JSON” para guardar o projeto; “Abrir JSON” recupera o arquivo. Imagens também são incluídas.
  4. No mini-livro, faça os vincos da grade, corte apenas o segmento central indicado, dobre ao meio no sentido comprido e aproxime as pontas para formar as oito páginas.
  5. No caleidociclo, recorte o contorno, vinque as diagonais, cole as abas para formar a corrente de tetraedros e una as extremidades sem torcer. Espere a cola secar antes de girar.

Use tesoura com supervisão de um adulto. Os modelos de papel são protótipos: faça uma montagem de teste antes de preparar uma turma.
