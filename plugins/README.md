# Escritor + Revisor — módulos editoriais

Dois módulos portáteis, sem dependência paga e com instruções em português brasileiro.

- `escritor/SKILL.md`: produção de textos, planejamento editorial e adaptação a públicos.
- `revisor/SKILL.md`: revisão gramatical, de estrutura, precisão e clareza.

## Fluxo de trabalho
**Briefing → Escritor → Revisor → Versão final**.

O revisor sempre recebe o texto integral e contexto do briefing. Ele não deve inventar fontes ou alterar a intenção original.

## Como usar
Copie o conteúdo do `SKILL.md` correspondente para as instruções de um agente personalizado, automação ou ambiente compatível com skills. Para trabalho coordenado, use ambos em sequência.

**Limitação:** estes são arquivos de configuração de agentes; colocá-los no GitHub **não instala um plugin dentro do ChatGPT**, nem disponibiliza automaticamente uma API de IA ao site. Uma integração nativa requer o respectivo ambiente, publicação e autorização.

## Critérios de aceite
- Texto completo e coerente em pt-BR;
- Preservação de nomes, dados e intenção;
- Sem bibliografia fabricada;
- Revisão que aponta o que é erro e o que é sugestão;
- Controle de qualidade em duas etapas.
