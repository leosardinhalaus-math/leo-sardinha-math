# Como usar Escritor e Revisor no ChatGPT

Os módulos em `escritor/SKILL.md` e `revisor/SKILL.md` são **instruções portáteis**, não plugins já instalados na conta.

## Uso imediato
Peça numa conversa: "Use o fluxo Escritor → Revisor. Tema: [tema]. Público: [público]. Gere um rascunho, revise gramática e coerência, entregue texto final e observações." O ChatGPT poderá realizar essas etapas nesta conversa sem instalar nada.

## Como transformá-los em recurso reutilizável
Copie as instruções de cada SKILL.md para um GPT personalizado ou projeto com instruções próprias, onde esse recurso estiver disponível. Criar e publicar integrações nativas exige ferramentas de desenvolvimento e as permissões da plataforma; um commit GitHub não altera configurações da conta.

## Privacidade
Não inclua chaves de API, documentos confidenciais ou dados pessoais de terceiros em instruções públicas. Não use o módulo de pesquisa Tookie OSINT como ferramenta de vigilância ou investigação de pessoas.
